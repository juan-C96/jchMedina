## 🚀 Características Técnicas

- **Framework:** Construido con las últimas características de Angular (Signals, Control Flow).
- **Estilos:** SCSS modular con variables CSS para un sistema de diseño mantenible (Dark Mode nativo).
- **Internacionalización (i18n):** Soporte multi-idioma integrado mediante Transloco.
- **Arquitectura de Componentes:** UI desacoplada siguiendo principios de desarrollo aplicados en librerías empresariales.
- **Animaciones:** Transiciones fluidas y scroll reveal personalizado sin abusar de librerías pesadas externas.

## 💼 Proyectos Destacados Incluidos

El portafolio expone algunos de mis desarrollos más relevantes:
1. **DevTools Hub:** Suite de utilidades 100% Client-Side (conversores JSON a TS, optimizadores SVG).
2. **Enterprise UI Libraries:** Experiencia en desarrollo y mantenimiento de sistemas de diseño B2C de alto tráfico.
3. **Jamstack Community Platform:** Arquitectura basada en exportación estática para máximo rendimiento.
4. **Location-Aware App:** Integraciones móviles en tiempo real.

## 🛠️ Instalación y Desarrollo Local

Para clonar y ejecutar este proyecto localmente, necesitas tener [Node.js](https://nodejs.org/) y [Angular CLI](https://angular.io/cli) instalados.

```bash
# 1. Clona el repositorio
git clone [https://github.com/juan-C96/jchMedina.git](https://github.com/juan-C96/jchMedina.git)

# 2. Navega al directorio del proyecto
cd jchMedina

# 3. Instala las dependencias
npm install

# 4. Levanta el servidor de desarrollo
ng serve
